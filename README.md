# ResearchOS

> Open Source Research Operating System for AI Agents.

ResearchOS is an Agent-first platform for autonomous research, knowledge evolution and engineering decision support.

## Vision

Build an open, private, extensible Deep Research platform combining:

- Agent Runtime
- MCP Tool Ecosystem
- Hybrid GraphRAG
- Long-term Memory
- Multi-model AI Gateway
- Automated Technical Report Generation

## Core Stack

- LangGraph Agent Runtime
- FastAPI Gateway
- LiteLLM Model Gateway
- MCP Tool Layer
- Neo4j + Qdrant Knowledge Layer
- MinIO Object Storage
- PostgreSQL Metadata Store
- Redis Runtime Cache
