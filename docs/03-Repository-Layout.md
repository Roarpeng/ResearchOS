# ResearchOS Repository Layout

```
ResearchOS/
├── frontend/
├── gateway/
├── runtime/
```

## frontend

## gateway

FastAPI service layer.

## runtime

## agents

Agent implementations.

## tools

MCP servers and tool adapters.

## knowledge

Document ingestion, retrieval and graph processing.

## deploy

Docker and production deployment resources.
