# ResearchOS Vision

## Product Definition

ResearchOS is an open source Research Operating System designed for autonomous AI agents.

It is not a chatbot, workflow engine or simple RAG system.

The goal is to create a persistent intelligence platform that can:

- research external information
- understand enterprise knowledge
- maintain long-term memory
- generate engineering decisions and reports

## Positioning

ResearchOS = Deep Research + Knowledge OS + Engineering Copilot.

## Target Scenarios

- Industrial technology research
- Competitor analysis
- Patent analysis
- Academic research
- Engineering solution design
- Enterprise knowledge intelligence

## Design Principles

1. Agent First
2. MCP Native
3. Knowledge Evolution
4. Model Independent
5. Private Deployment
6. Documentation Driven Development

## Long Term Goal

Provide an open foundation similar to an operating system for AI research agents.
